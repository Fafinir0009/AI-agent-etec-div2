# Stack Técnica

## Stack principal

- Framework: Next.js
- Linguagem: TypeScript
- Banco de dados: SQLite
- Autenticação: login administrativo para cadastro de notícias
- Estilo e UI: componentes responsivos com foco em mobile first
- Compatibilidade: navegadores modernos

## Justificativa

- Next.js oferece uma base moderna e confiável para sites institucionais.
- TypeScript reduz erros e melhora manutenção do código.
- SQLite atende ao momento atual do projeto com simplicidade e baixo custo operacional.
- A estrutura permite evoluir para um painel administrativo sem perder estabilidade.

## Objetivos da stack

- Garantir velocidade de desenvolvimento.
- Apoiar uma interface acessível e visualmente atrativa.
- Facilitar manutenção de conteúdos e notícias.
- Suportar o catálogo de cursos técnicos e matrizes curriculares.

## Observações

- O banco SQLite é considerado suficiente para a fase inicial.
- O sistema deve permitir expansão futura, se necessário, sem reescrever toda a arquitetura.
