# Roadmap

## Fase 1 - Base do projeto
- Definir estrutura do site e conteúdo inicial.
- Configurar a stack Next.js com TypeScript.
- Preparar a base de dados SQLite.

## Fase 2 - Fundação visual
- Construir layout institucional e identidade visual.
- Desenvolver a navegação principal.
- Validar responsividade em dispositivos móveis.

## Fase 3 - Conteúdo acadêmico
- Incluir catálogo de cursos técnicos.
- Inserir matrizes curriculares por curso.
- Revisar descrições e matérias dos cursos.

## Fase 4 - Notícias e administração
- Implementar página inicial com destaque para notícias.
- Criar login administrativo para cadastro de notícias.
- Persistir notícias no SQLite.

## Fase 5 - Validação e publicação
- Revisar compatibilidade em navegadores modernos.
- Testar fluxos principais do site.
- Publicar a versão inicial do projeto.
